The 267-article backlog is now fully published. This is the *new* forward pipeline so the site keeps gaining fresh, sleep-positioned depth (Google rewards freshness + topical authority) and starts winning the high-intent **sleep-app** and **comparison** searches that competitors (nappi, NapNap, Huckleberry, Napper) currently own.

## How to run it
- **Cadence:** 3 posts/week (Mon / Wed / Fri). ~39 posts over 13 weeks.
- **Each post:** create `content/blog/<slug>.md` with front matter `title`, `date`, `heroImage`, `description`, `status: draft` until finished. The publish gate is currently **publish-all** (new posts go live when committed). To drip instead, set `BLOG_DRIP_SCHEDULE=1` and date posts forward.
- **Every post must:** (1) target the primary keyword in title + H1 + first 100 words, (2) lead with the sleep-fix angle, (3) cite a concrete OBubba proof point (personal-rhythm nap prediction, sleep-brain "why", Luna coaching), (4) internal-link to 2-3 existing articles + the app download + the relevant landing page (`/baby-sleep-tracker.html`, `/baby-nap-tracker.html`, `/baby-wake-window-tracker.html`, `/baby-sleep-consultant-app.html`).
- **Priority order:** commercial/comparison first (fastest revenue), then pillar guides, then long-tail.
